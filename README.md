# Repository for Singh et al., Competing molecular interactions govern dynamical arrest in G3BP1 condensates - Simulation Analysis 
### This repository contains the data and analysis represented in Figure 6A-6L and Supplementary Figure 16 of the manuscript.

g3bp1_data: contains coordinates and cluster data for G3BP1-only simulations corresponding to different scaling factors

g3bp1_rna_data: contains coordinates and cluster data for G3BP1 + RNA simulations corresponding to different scaling factors and RNA lengths

Singh_manuscript.ipynb: contains scripts for analyzing simulation data
